## 1. 利用者ができること・範囲

- `/tools/cable-position-comparison/` で未測定の経路比較と、RSSI／RSRPの前後または差だけの記録を切り替えます。
- 未知と0を分離。条件がそろう場合に経路差・分岐点・配置効果を含む予測を表示します。測定記録からケーブル差を再減算しません。
- 係数連動、mm/cm/m、MHz/GHz、入力途中の保護、方式ごとの下書き、根拠・周波数適用を扱います。
- 明示操作で1件保存、復元・削除、JSON読込／書出し、相談文コピー、ブラウザー印刷、既存窓口への移動ができます。

- P1の製品候補比較、P2のVSWR比較、クラウド同期、通信・認証・採用保証は対象外です。

### 数式

`L = lengthM × lossDbPerM + connectorsTotalLossDb`、完成経路は `L = totalLossDb`。
`ΔL = L_after − L_before`、`predictedNetDb = G − ΔL`、分岐点は `G = ΔL`。
測定は `recordedDeltaDb = afterDbm − beforeDbm` または直接記録差。その後に損失を引きません。
演算のゼロ許容誤差1e−9 dBは測定誤差を意味しません。
